# Walmart AI Listing Generator

A powerful hybrid tool that automates the creation of optimized Walmart product listings. It leverages a **Chrome Extension** for robust client-side scraping (bypassing server-side bot detection) and a **Google Apps Script (GAS)** backend for secure AI processing using OpenAI's **GPT-4o Vision**.

## 🚀 Key Features

*   **Client-Side Scraping Engine**: Runs directly in your browser to bypass Walmart's strict "Robot or Human" CAPTCHAs and bot detection.
*   **Hybrid AI Architecture**:
    *   **Extension**: Handles data extraction (Images, Title, Description, Specifications, Variants).
    *   **GAS Backend**: Orchestrates OpenAI API calls, validation, and Sheet updates.
*   **Rich Data Extraction**: Parses internal page JSON (`__NEXT_DATA__`) to extract deep product details like "About this item", ingredients, and specifications, not just visible text.
*   **Multi-Input Support**: Accepts both full URLs (`https://www.walmart.com/ip/...`) and raw Product IDs (`673227921`).
*   **Resume & Retry Capability**: Automatically skips "DONE" rows. Failed rows are marked as "Failed" and automatically retried in the next run.
*   **Robust "Keep-Alive" System**: Uses the Chrome `Offscreen` API and `Content Scripts` to keep the processing engine running even if Chrome is minimized or the popup is closed.
*   **Smart Validation**: Checks for title length (matches Walmart's 200 char limit), bullet point count, and flagged terms.
*   **Cost-Efficient AI**: Uses `gpt-4o-mini` for text heavy lifting and fallbacks, optimizing for speed and cost.

---

## 🛠️ Architecture

1.  **Google Sheet**: Acts as the database. Contains Product URLs/IDs and Keywords.
2.  **Chrome Extension**:
    *   Reads pending items from GAS.
    *   Visits Walmart pages in the background.
    *   Scrapes data (Images + Metadata).
    *   Sends payload back to GAS.
3.  **Google Apps Script (GAS)**:
    *   Receives scraped data.
    *   Constructs a prompt with images + rich text.
    *   Calls OpenAI API.
    *   Validates output.
    *   Writes Title, Bullets, Description to the Sheet.

## 📦 Installation & Setup

### 1. Google Sheets & Apps Script Setup
1.  Create a new Google Sheet.
2.  Set up the **Header Row** (Row 1) exactly as follows:
    *   **Col A**: Product URL / ID
    *   **Col B**: Keywords
    *   **Col C**: Product Title (AI Output)
    *   **Col D**: Bullet Points (AI Output)
    *   **Col E**: Description (AI Output)
    *   **Col F**: Status
3.  Go to **Extensions > Apps Script**.
4.  Copy the code from `FIXED_GAS_CODE.gs` into the editor.
5.  **Critical**: Paste your OpenAI API Key into the `OPENAI_API_KEY` variable at the top of the script.
6.  Click **Deploy > New Deployment**.
    *   **Type**: Web App.
    *   **Access**: Anyone (or Anyone with Google Account).
7.  **Copy the Web App URL**. You will need this for the Extension.

### 2. Chrome Extension Setup
1.  **Build the Project** (if you have the source):
    ```bash
    yarn install
    yarn build
    ```
2.  **Load into Chrome**:
    *   Open `chrome://extensions`.
    *   Enable **Developer Mode** (top right).
    *   Click **Load unpacked**.
    *   Select the `dist` folder generated by the build.

## 🖥️ Usage Guide

1.  **Prepare Data**: Paste your Walmart URLs or Product IDs in **Column A** of your Google Sheet. Add keywords in **Column B**.
2.  **Open Extension**: Click the extension icon in Chrome.
3.  **Configure**:
    *   Paste the **Google Sheet URL**.
    *   Paste the **GAS Web App URL** (from the deployment step).
    *   Click **Save**.
4.  **Start Job**:
    *   Click **Generate Listings**.
    *   The status in the extension will update to show progress.
    *   **Pro Tip**: You can minimize Chrome or work on other tabs. The "Offscreen" system keeps the scraping active.

## 🔍 Troubleshooting

| Status (Col F) | Meaning | Action |
| :--- | :--- | :--- |
| **DONE** | Successfully generated. | None. This row will be skipped next time. |
| **DONE (Warning)** | Generated, but triggered a flagged term or warning. | Review the content manually. |
| **Failed** | Basic error (Timeout, Image Error). | Run the extension again. It will auto-retry. |
| **Quota Exceeded** | OpenAI API credits run out (Error 429). | Check your OpenAI billing/credits. |
| **API Key Missing** | Script doesn't have the key. | Check `FIXED_GAS_CODE.gs` line 175. |
